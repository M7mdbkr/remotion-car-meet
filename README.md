# Car Meet Motion

Remotion composition work for a vertical car-meet edit.

## What it demonstrates

- Timeline-driven clip sequencing
- Per-clip timing, volume, and zoom interpolation
- Video and audio composition with React components
- Vertical social-video framing and reusable composition structure

## Stack

Remotion · React · TypeScript · Tailwind CSS

## Run locally

```bash
npm install
npm run lint
npm run dev
```
